# Twisted Racing

Боевые кольцевые гонки в изометрии: вид как в Rock n' Roll Racing, бой как в Twisted Metal, пустоши в духе «Безумного Макса». Сначала браузер, потом Android (Capacitor).

Документы: [концепция](docs/concept.md), [план разработки](docs/plan.md).

## Играть

Свежая версия из ветки `main`: https://causemen.github.io/twisted-racing/

Публикуется автоматически после каждого изменения в `main` (`.github/workflows/deploy.yml`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run typecheck
```

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Газ / тормоз | ↑ ↓ или W S | газ автоматический, кнопка ТОРМОЗ |
| Руль | ← → или A D | ◀ ▶ |
| Пулемёт | Пробел | ОГОНЬ |
| Ракеты / мины | Shift | РАКЕТА/МИНА |
| Нитро | E | НИТРО |

Поддерживается геймпад (стик, курки, A/B/X).

## Структура

| Файл | Что внутри |
|---|---|
| `src/config.ts` | Все числа баланса: скорость, урон, перезарядки |
| `src/track.ts` | Трасса: центральная линия, полотно, ограждение, трамплины, декор |
| `src/car.ts` | Аркадная физика машины и её модель |
| `src/combat.ts` | Пули, ракеты, мины, ящики с оружием, урон |
| `src/bot.ts` | Боты |
| `src/particles.ts` | Взрывы, дым, искры |
| `src/hud.ts` | Интерфейс, мини-карта, результаты |
| `src/main.ts` | Сцена, камера, игровой цикл |

Модели пока собраны из примитивов прямо в коде, бесплатные ассеты подключим на этапе вертикального среза.
