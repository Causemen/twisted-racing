# Twisted Racing — план разработки

*Версия 0.1, 9 октября 2026. Дополняет [concept.md](concept.md).*

## 1. Технологии и инструменты

**Выбор движка.** Рекомендую **Three.js + TypeScript** с фиксированной изометрической (ортографической) камерой, а не 2D-движок вроде Phaser.

Почему:
- Трамплины, перепады высот и прыжки в 3D получаются естественно, а в 2D их приходится имитировать.
- Машина свободно поворачивается на любой угол. В 2D для каждой машины пришлось бы рисовать 16–32 спрайта поворота, и ещё столько же для каждой стадии повреждений.
- Взрывы, разлетающиеся детали, огонь и свет выглядят современнее, а вид остаётся «как на Сеге».
- Те же модели пойдут в будущем на телефоны без переделки.

Альтернатива: Babylon.js (в нём больше всего «из коробки», но тяжелее файл). Phaser 3 подходит, только если хотим чисто пиксельный 2D-стиль.

| Задача | Инструмент |
|---|---|
| Язык и сборка | TypeScript, Vite |
| Графика | Three.js |
| Физика машин | Rapier (WASM, есть готовый контроллер машины) |
| Звук | Howler.js |
| Интерфейс и меню | HTML/CSS поверх игры (или Preact) |
| Сборка в APK | Capacitor (обёртка веб-игры в Android-приложение) |
| Онлайн-мультиплеер (этап 2) | Colyseus (Node.js сервер комнат) |
| Аккаунты, сохранения, рекорды | Supabase (уже подключён к проекту как коннектор) |
| 3D-модели | Blender (бесплатно), формат glTF |
| Редактор трасс | Blender или свой простой редактор на базе игры |
| Хранение кода | GitHub, приватный репозиторий |
| Публикация браузерной версии | itch.io, CrazyGames, Poki, свой сайт (Vercel/Netlify) |
| Аналитика | GameAnalytics (бесплатно) |
| Задачи | GitHub Issues/Projects |

## 2. Этапы

### Этап 0. Подготовка
- Создать репозиторий, каркас проекта (Vite + TS + Three.js + Rapier).
- Настроить автодеплой браузерной сборки, чтобы после каждого изменения можно было сразу играть по ссылке.

### Этап 1. Прототип «ощущения» (самое важное)
- Одна трасса из серых блоков, изометрическая камера.
- Управление машиной: газ, руль, дрифт, прыжок с трамплина.
- Пулемёт и одна ракета, полоса здоровья, взрыв и возрождение.
- 3 простых бота, едущих по линии.
- **Критерий выхода:** в это уже весело играть даже с кубиками вместо машин. Если нет, правим физику и камеру, пока не станет.

### Этап 2. Вертикальный срез (одна территория «как в релизе»)
- 1 трасса в финальной графике, 3 машины, весь набор оружия.
- Счёт кругов, позиции, финиш, экран результатов.
- Звук, музыка, эффекты.
- Управление на телефоне, первая сборка APK через Capacitor и проверка на реальном слабом устройстве.

### Этап 3. MVP (основной продакшн)
- 6 машин, 5 территорий, 10 трасс.
- Кампания, гараж и улучшения, сохранения.
- Боты разной сложности и характера, боссы.
- Меню, настройки, обучение.
- Выпуск браузерной версии на itch.io / CrazyGames для сбора отзывов.

### Этап 4. Мобильный релиз
- Оптимизация под Android (качество графики по уровням).
- Реклама и покупки (см. монетизацию).
- Аккаунт разработчика Google Play (разовый взнос 25 $), страница магазина, закрытое тестирование (Google требует 12+ тестировщиков 14 дней для новых личных аккаунтов).
- Релиз в Google Play.

### Этап 5. Онлайн
- Сервер Colyseus, комнаты до 6 игроков, подбор соперников.
- Сервер считает урон и позиции, чтобы нельзя было читерить.
- Рейтинги, сезоны.

### Дальше
- Новые машины и трассы как обновления, ежедневные испытания, iOS при желании.

## 3. Как организуем производство

- Работаем короткими итерациями: каждая заканчивается играбельной сборкой по ссылке.
- Код пишу я (Claude) в репозитории через pull request’ы, Роман играет, даёт отзыв и принимает решения.
- Вся настройка баланса (скорость машин, урон оружия) в отдельных файлах конфигурации, чтобы её можно было менять без программирования.
- Документ концепции остаётся главным ориентиром, изменения в нём обсуждаем.

## 4. Графика

**Стиль:** низкополигональный 3D с «грязными» текстурами, крупными силуэтами и яркими эффектами огня. С изометрической камеры сверху детали всё равно мелкие, поэтому важны силуэт и цвет, а не полигоны.

**Откуда брать:**
1. **На прототипе:** простые кубы и бесплатные паки (Kenney.nl, Quaternius, CC0-лицензия).
2. **Дальше:** купленные паки на itch.io / Sketchfab / Unity Asset Store (форматы FBX/glTF подходят) плюс доработка в Blender.
3. **Для уникального стиля:** заказать 6 машин и набор деталей трасс у 3D-художника (фриланс). Это самая заметная статья расходов.
4. **ИИ-генерация** (Meshy, Tripo и подобные) годится для концептов и второстепенных объектов, но машины лучше делать вручную, иначе стиль будет разнобойным.

**Технические рамки для телефона:** машина до ~3–5 тыс. треугольников, общая текстура-атлас на трассу, запечённое освещение, эффекты частицами. Три уровня качества графики в настройках.

**Интерфейс:** стилизованные шрифты и рамки «из металлолома», крупные кнопки для пальцев.

## 5. Монетизация

Принцип: никакой продажи силы. Иначе бой перестаёт быть честным и игроки уходят.

| Источник | Где | Комментарий |
|---|---|---|
| Реклама за награду | Браузер (через SDK CrazyGames/Poki) и Android (AdMob) | «Посмотри ролик и получи двойную горючку / бесплатный ремонт». Основной доход на старте |
| Межстраничная реклама | Между заездами, не чаще раза в 2–3 гонки | Отключается покупкой «Без рекламы» |
| «Без рекламы» | Разовая покупка | Простая и любимая игроками покупка |
| Косметика | Покраски, наклейки, черепа на капот, следы и взрывы | Основной доход в долгую |
| Новые машины | Можно открыть игрой или купить сразу | Машины разные по стилю, а не сильнее |
| Боевой пропуск (сезон) | После запуска онлайна | Награды за игру, премиальная ветка за деньги |

Браузерные порталы (Poki, CrazyGames) делятся доходом с рекламы и дают трафик бесплатно: хороший способ проверить интерес до вложений в Google Play.

## 6. Риски

- **Физика машин на телефоне:** проверяем на слабом устройстве уже на этапе 2.
- **Онлайн сложнее, чем кажется:** поэтому сначала одиночная игра с ботами.
- **Авторское право:** не используем названия, персонажей и музыку из «Безумного Макса», Twisted Metal и Rock n' Roll Racing.
- **Объём графики:** держим набор машин и трасс маленьким до проверки интереса.
